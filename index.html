For Caregivers: Get Sunny on a Loved One's Computer

Three steps. No technical skills needed. Sunny runs entirely offline after install.

Windows 10 / 11

Download for Windows
  1. Click the button above. File downloads automatically
  2. Open Downloads/Sunny-Setup.exe
  3. If Windows says "Windows protected your PC", click More info, then Run anyway
  4. Follow the installer (Next, Next, Finish)

macOS 12+

Download for macOS
  1. Click the button above. File downloads automatically
  2. Open Downloads/Sunny-*.dmg
  3. Drag Sunny into the Applications folder
  4. First launch: System Settings - Privacy & Security - Allow Sunny

Linux (Debian / Ubuntu)

Download for Linux
  1. Click the button above. File downloads automatically
  2. Open terminal in Downloads folder
  3. Run: sudo dpkg -i sunny_*_amd64.deb
  4. Launch "Sunny" from app menu

Straight answers, in plain language

Does Sunny cost anything?

No. Sunny is free and open source. No subscriptions. No ads. No hidden fees.

Do I need an internet connection?

Internet helps Sunny fetch recipes, weather, and news. Basic help works without it.

Can Sunny be tricked into doing something dangerous?

No. Sunny refuses terminal commands, passwords, network scanning, or hacking. Every sensitive action asks permission first and defaults to No.

Which computers does Sunny run on?

Windows, macOS, and Linux. Not sure? Start with the Windows download. It's the easiest.
